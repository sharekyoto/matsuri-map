# 祭りマップ

50年以上つづく日本の祭りを地図で探すサイト。**開催日**でも**現在地からの距離**でも、
**屋台あり・神輿あり・福引あり**などの要素でも絞り込めます。
運用コストはゼロ（GitHub Pages + GitHub Actions の無料枠のみ）。

---

## いますぐ見る（GitHub 不要）

`matsuri-map-standalone.html` をダブルクリックしてブラウザで開くだけ。
115件の初期データが埋め込まれています。地図タイルの表示にネット接続だけ使います。

---

## 公開する（GitHub Pages・無料）

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身をまるごとアップロード（Web の「uploading an existing file」でドラッグ&ドロップでも可）
3. リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選ぶ
4. **Actions** タブ →「祭りデータ月次更新 & 公開」→ **Run workflow** を押す

初回実行で数千件の全国データが収集され、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
以後は**毎月2日の朝5時（JST）に自動で更新**されます。

スマホでそのURLを開き「ホーム画面に追加」すると、アプリのように使えます（PWA対応・オフラインでも直前のデータを表示）。

## 手元で動かす

```bash
pip install -r scripts/requirements.txt

python3 scripts/seed.py        # 初期データ（115件）を作る
python3 scripts/build.py       # 全国データを収集（30〜80分。数千件）
python3 scripts/validate.py    # 生成物の検証
python3 scripts/standalone.py  # 単体HTMLを作り直す

python3 -m http.server 8000    # → http://localhost:8000
```

動作確認だけしたいときは `python3 scripts/build.py --limit 300 --no-geocode`（数分で終わります）。

## データはどこから来るか

| ソース | 使うもの | ライセンス |
|---|---|---|
| 日本語版Wikipedia「日本の祭一覧」 | 祭りの名称・市町村・開催日表記 | CC BY-SA 4.0 |
| 同 Category:日本の祭り (都道府県別) ほか | 小さな地元の祭りの記事 | CC BY-SA 4.0 |
| 同 記事本文 | 要素タグ・創始年・文化財指定の判定 | CC BY-SA 4.0 |
| Wikidata (P625) | 座標の補完 | CC0 |
| 国土地理院 ジオコーディングAPI | 市区町村からの座標補完 | 出典明記で利用可 |
| 国土地理院 淡色地図タイル | 背景地図 | 出典明記で利用可 |
| `data/manual.csv` | 自分で書き足した祭り | 自由 |

APIキーは一切不要です。

### 「50年以上」をどう判定しているか

記事本文から創始年を読み取り、確度をレコードごとに記録しています。
表示にもバッジで出るので、鵜呑みにせず判断できます。

| 確度 | 判定のしかた | 表示 |
|---|---|---|
| `exact` | 「◯◯年に始まった」など創始の文脈のすぐそばに西暦・元号があった | `320年つづく（1706年〜）` |
| `estimated` | 本文中の最も古い年、または「江戸時代」などの時代名から推定 | `約270年つづく（推定）` |
| `proxy` | 年の記述はないが、国・県・市の文化財指定がある | `文化財指定・50年以上` |
| `assumed` | 「伝統」「古くから」「例大祭」等の語から50年以上とみなした | `50年以上（推定）` |
| `unknown` | 判断材料なし → 既定の表示から除外 | — |

元号は大化〜令和まで全対応。旧暦は `lunardate` で新暦に換算しています（近似）。

## 開催日の展開

Wikipedia の日付は自然文です。`scripts/dates.py` がこれをルールに落として、
今後3年ぶんの実日付に展開します。

| 表記 | 展開結果（2026年） |
|---|---|
| `8月3日から6日` | 8/3〜8/6 |
| `8月第1金曜から3日間` | 8/7〜8/9 |
| `9月の敬老の日を含む土日月` | 9/19〜9/21 |
| `10月第2土曜日を中日とする金曜、土曜、日曜日` | 10/9〜10/11 |
| `7月下旬の土曜日` | 7/25 |
| `旧暦6月15日` | 7/28（ごろ） |
| `5月中旬` | 5/11〜5/20（ごろ） |
| `72年間隔・次回は2075年` | 不定期として記録 |

「ごろ」が付くものは推定日です。`python3 scripts/dates.py` で確認できます。

## 絞り込める項目

**祭りの要素** — 屋台・露店／神輿／山車・曳山／花火／提灯・灯籠／福引・餅まき／地元グルメ・振る舞い／行列・仮装／キリコ・大灯籠

**伝統芸能・神事** — 神楽／獅子舞／盆踊り／田楽・田植神事／能・狂言・歌舞伎／流鏑馬・馬事／太鼓・囃子／踊り・よさこい

**祭りの性格** — 裸祭り／火祭り／けんか祭り／水・海の祭り／奇祭／雪の祭り／花・自然の祭り／正月・年越し行事

**規模・格付け** — ユネスコ無形文化遺産／国指定重要無形民俗文化財／国選択／県指定／市町村指定／日本三大○○／大規模

**アクセス・実用** — 夜間開催／有料観覧席あり／子ども歓迎／駅から徒歩圏

**そのほか** — 継続年数（50/100/200/300/500年以上）、都道府県、月、日付範囲、現在地からの距離（10〜200km）、キーワード

項目を増やしたいときは `scripts/taxonomy.py` の `TAGS` に1行足すだけです。
フロントエンドのチェックボックスは自動で増えます。

## 自分で祭りを書き足す

Wikipedia に記事のない集落レベルの祭りは `data/manual.csv` に追記してください。

```csv
name,pref,city,lat,lng,when,founded,tags,url,note
○○神社秋季例大祭,京都府,京都市,35.0100,135.7700,10月第2日曜日,1780,mikoshi|yatai|fukubiki,,子ども神輿と餅まき
```

`when` は日本語のまま書けます。`lat`/`lng` を空にすると市区町村名から座標を補います。
`build.py` を実行するたびに自動でマージされ、月次更新で上書きされることもありません。

## ファイル構成

```
index.html                     サイト本体（Leaflet地図・全UI）
matsuri-map-standalone.html    データ埋め込み済みの単体版
manifest.webmanifest / sw.js   PWA（ホーム画面追加・オフライン）
icon.svg
data/
  festivals.json               公開されるデータ（build.py が生成）
  seed.json                    初期データ115件（seed.py が生成）
  manual.csv                   手入力ぶん
scripts/
  build.py                     収集パイプライン本体
  dates.py                     日本語の日付表記 → 実日付
  taxonomy.py                  タグ体系とキーワード辞書
  wareki.py                    和暦・時代名 → 西暦、創始年の推定
  seed.py                      初期データ生成
  validate.py                  生成物の検証
  standalone.py                単体HTMLの生成
.github/workflows/update.yml   月次更新 + Pages公開
```
